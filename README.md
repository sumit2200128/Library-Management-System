# 📚 Library Management System

A full-stack, web-based **Library Management System** built using Node.js, Express, MongoDB, and modern vanilla JavaScript frontend. This system automates essential library operations including book issuing, returns, user authentication, role-based authorization, fine management, and membership tracking.

---

## 🚀 Features

### 👤 User Management & Authentication
- **User Registration & Login**: Secure authentication system using JWT (JSON Web Tokens) or session-based credentials.
- **Role-Based Access Control (RBAC)**: Distinct permissions for **Admin / Librarians** and **Members / Students**[cite: 1].
- **Membership Plans**: Track active user memberships, issue limits, and expiration dates[cite: 1].

### 📖 Book & Inventory Management
- Catalog management for adding, updating, searching, and deleting book records[cite: 1].
- Real-time availability status for each title (Available / Issued)[cite: 1].

### 🔄 Issue & Return Transactions
- **Book Issue System**: Borrow books with automated due date calculation[cite: 1].
- **Book Return System**: Process returns and auto-calculate overdue days[cite: 1].
- **Fine Management**: Automated fine calculation based on return delay[cite: 1].

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3, JavaScript (Vanilla ES6+)[cite: 1]
- **Backend**: Node.js, Express.js[cite: 1]
- **Database**: MongoDB (Mongoose ODM)[cite: 1]
- **Authentication**: Role-based access control with Express routes[cite: 1]
